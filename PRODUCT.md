# Growth Brain — Product Truth

## 核心結果
打開網站後，先回答四件事：我的方向是什麼、現在最該做什麼、為什麼、做到什麼算有證據。

## Surface 分工

### Personal Home
只放會影響使用者個人成長與作品路線的資訊：
- primary direction
- one next action
- why now
- success evidence
- learning support
- Synapse highlights
- recent real progress

### System Cockpit
只放系統建置與 AI 團隊運作：
- current build step
- deployment / auth status
- blockers
- work queue
- skill team
- runtime truth

## 不可破壞規則
- System build route 不可冒充 Personal Home 主線。
- AI 解釋不算使用者已學會。
- planned skill 不冒充 executed。
- project-specific learning prompt 未與 personal outcome route match 前，不升格成首頁 CTA。
- secret / service role 不進瀏覽器。
- cached / live 資料必須可分辨。
- single-user private 不提供 signup。
