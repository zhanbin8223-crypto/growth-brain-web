# 設計：導覽收斂為 5 頁

## 個人頁（主導覽）
| 頁 | 唯一目的 | 內容 | 主要按鈕 |
|---|---|---|---|
| 今天 | 決定並推進目前作品的下一步 | 無目前作品：兩張作品卡；已選：進度環＋唯一下一步＋等待中作品；卡住時才出現「學習補一下」卡 | 「開始這一步」／「選這件開始」 |
| 作品 | 看兩件作品與各自進度、交證據 | 作品清單（進行中／等待中／已完成／預計，同頁篩選）、完成條件與證據 | 「交出證據」 |
| 學習 | 補足目前步驟需要的能力 | 下一個學習任務、練習、「我的能力」區（能力庫、能力變化）、作戰手冊與知識關係為展開內容 | 「送出練習」 |
| 收集 | 先放進來，之後分類 | 收件匣＋研究候選；今日探索／AI／流量／商業／GB 為標籤篩選 | 「＋ 收集」 |
| 回顧 | 看真的發生過什麼 | 我的歷程＋研究歷程（時間軸） | 「看本週」 |

## 系統（右上齒輪）
| 頁 | 目的 | 內容 |
|---|---|---|
| 待處理 | 還沒完成的事（置頂） | 現在團隊/系統維護頂部的待處理區塊 |
| AI 團隊 | 角色、使用紀錄、試用狀態 | 團隊/正在工作、我的老師、研究員 |
| 系統狀態 | 工作包、Worker、版本歷程 | 團隊/系統維護其餘內容＋歷程/版本歷程 |

## 現有 view → 新歸屬
| 現有 view（key） | 新歸屬 | 方式 |
|---|---|---|
| 今天 (home) | 今天 | 保留 |
| 作品 (projects)：進行中／已完成／預計作品 | 作品 | 子頁改為同頁篩選 |
| 能力庫 (capabilities)：我的技能 | 學習 › 我的能力 | 合併 |
| 能力庫：作戰手冊、知識關係 | 學習（展開內容） | 不獨立成頁 |
| 學習 (learn，原隱藏) | 學習 | 升為主導覽 |
| 知識連結圖 (synapse，原隱藏) | 學習（展開內容） | 合併 |
| 收件匣 (inbox，原隱藏) | 收集 | 合併 |
| 研究室 (research)：今日探索／AI／流量／商業／GB | 收集 | 改為標籤篩選 |
| 歷程 (history)：我的歷程、能力變化 | 回顧；能力變化 → 學習 › 我的能力 | 合併 |
| 歷程：研究歷程 | 回顧 | 合併 |
| 歷程：版本歷程 | 齒輪 › 系統狀態 | 移出個人導覽 |
| 團隊 (ceo)：正在工作、我的老師、研究員 | 齒輪 › AI 團隊 | 移出個人導覽 |
| 團隊：系統維護（待處理區塊） | 齒輪 › 待處理 | 移出個人導覽 |
| 團隊：系統維護（其餘） | 齒輪 › 系統狀態 | 移出個人導覽 |

舊 view key（capabilities、research、ceo、history、inbox、synapse）以 setView 對照表導向新頁，舊書籤不壞。
