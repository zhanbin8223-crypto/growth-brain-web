# 變更提案：5 個主頁＋每頁頂部功能捷徑列（navigation-5-pages）

狀態：proposed（使用者已確認需求修訂版，待核准後才實作）　決策紀錄：docs/decisions/0002-navigation-5-pages.md

## Why
現行有 6 個主頁、多個子頁與 3 個隱藏頁（收件匣、學習、知識連結圖）。同一件事有多個名字、學習與收集被藏起來、系統維運混在個人導覽。
研究室的「今日探索」充滿未解釋術語，卡片停在「保留／忽略／送進試驗」三選一後就沒有下一步。使用者常不知道自己在哪、能做什麼、下一步是什麼。

## What Changes
- 主導覽 5 頁：今天、作品、學習、研究室、收集。
- 每個主頁頂部有「功能捷徑列」，列出該頁全部功能；點一下就切換，不必捲動找功能。不把多個功能硬塞成一條長頁。
- 研究室保持獨立頁：給 AI 研究代理自由思考、上網查資料、自我迭代的空間。
- 回顧改為「作品」頁的一個分頁（理由見 design.md）。
- 系統維運收進右上齒輪：待處理（第一）、AI 團隊、系統狀態。
- 今日探索改為「AI 推薦你看的一件事」：一句白話＋一個按鈕；術語第一次出現必附白話解釋。
- 每頁固定顯示「你在哪（頁＋分頁）」、「這裡能做什麼（捷徑列）」、「下一步（唯一主要按鈕）」。
- 移除英文眉標（TODAY / ARTIFACTS / LAB 等）。

## Scope
- 前端導覽、頁內捷徑列、頁首文案、主要按鈕、今日探索卡片呈現。
- 不改 Supabase schema、RPC、Edge Function 與資料。

## Future scope（本次不做）
- 研究室的 AI 研究代理擁有並經營自己的個人網站。只記錄方向，不設計、不實作。
- 研究代理的自主迭代排程（需 Worker 恢復與另行核准）。

## Forbidden scope
- 不得刪除任何既有功能，只能搬到某頁的某個分頁。
- 不得把多個分頁合併成需要捲動才找得到的長頁。
- 不得把系統頁放回個人主導覽。
- 不得改動學習、證據、能力的判定規則。

## Impact
- 前端：index.html、app.js（setView、各 render 掛載點）、event-lab.js（今日探索）、styles.css。
- 測試：依賴 data-view／subtab 名稱的測試同步更新；舊 view key 需導向新頁＋分頁。

## Rollback
單一 PR 實作；回滾＝ revert 該 PR 並重新部署 GitHub Pages。不涉及資料或 schema。
