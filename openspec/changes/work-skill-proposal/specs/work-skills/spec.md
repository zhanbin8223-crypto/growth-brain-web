# work-skills

## ADDED Requirements

### Requirement: 系統建議、使用者確認後才儲存
作品沒有能力清單時，系統 SHALL 依完成條件提出建議，且 MUST 在使用者按「確認儲存」後才寫入。

#### Scenario: 新作品產生建議
- WHEN 使用者對沒有能力的作品按「依完成條件產生建議清單」
- THEN 顯示可編輯清單，標示建議方式為規則範本（未使用 AI 模型），尚未寫入資料庫

#### Scenario: 確認儲存
- WHEN 使用者修改後按「確認儲存」
- THEN 寫入能力，所有新能力程度為「沒試過」，並記錄來源與確認日期

### Requirement: 自評不升級
「我可能會」MUST 只記錄待確認，不得改變 evidence_state。

#### Scenario: 標記我可能會
- WHEN 使用者在能力詳情按「我可能會」
- THEN 顯示「已標記：我可能會（待確認）」，程度標籤不變

### Requirement: 能力圖譜簡化
每個能力列 SHALL 只顯示名稱與一個程度標籤（可加「兩件都用到」），篩選全部／我已經會的／還沒會的，頁面只有一個主要按鈕。

#### Scenario: 手機詳情
- WHEN 手機上點一項能力
- THEN 詳情以固定在畫面底部、全寬的抽屜開啟，背景遮罩覆蓋全畫面，Esc／關閉可收起
