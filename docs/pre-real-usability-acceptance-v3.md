# Pre-real usability acceptance v3

Development-track contract only; this does not claim real-world acceptance.

- Path/artifact trial renders only the current stage.
- Current stage shows one goal, one deliverable artifact, and one rule for deciding the next stage.
- Future stages are not rendered before artifact evidence or user feedback exists.
- `blocked_external` is shown as 「外部能力受阻」.
- User-facing terms prefer 「知識連結」「學習單元」「正式個人資料」 over unexplained internal labels.
- Knowledge-link UI must distinguish loading / empty / error / ready.
- Cached or demo data may never impersonate live personal data.
- Trial output is non-persistent and cannot become personal progress, Learning evidence, or personal Synapse.

Security follow-up:
- Browser uses authenticated `growth-home`.
- Privileged Synapse RPCs should be callable by service-role only after migration verification.
