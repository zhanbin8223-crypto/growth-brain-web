## 結構測試

14 個只读條件測試全部取得預期結果：

| 案例 | 預期判定 |
|---|---|
| 沒有必要驗收條件 | 先定義驗收，不能算完成 |
| 工具成功但沒有證據 | 先診斷，不能算完成 |
| 還有可執行工作 | 繼續操作 |
| 第一次失敗 | 診斷根因 |
| 已診斷但未參考相關技能 | 載入技能 |
| 未確認工具能力 | 檢查本輪工具 |
| 未評估合法替代方式 | 評估替代方法 |
| 準備完成但問題未修好 | 修復並重測 |
| 額度限制且已有證據與恢復點 | 保留進度等待 |
| 重試預算耗盡且已有檢查點 | 暫停並要求新證據，不宣稱完成 |
| 用測試資料冒充真實驗收 | 不通過 |
| 必要驗收全部有匹配證據 | 允許結案 |
| 未經允許修改驗收標準 | 恢復原驗收 |
| 明確安全拒絕 | 尊重限制，不換通道繞過 |

正向案例中的 real 標籤屬於測試樣本，不能把這張表當作已驗證外部工具或瀏覽器。函式只驗證報告結構和判定規則，外部證據仍需另行核對。

## 真實流程查核

本輪另以一筆使用者明確選定的學習輸入，驗證既有收件、路由、學習單元及中文卡片保存，再從正式學習查詢函式讀回。重放同一請求後仍只有一筆收件項和一個學習階段；沒有自動選定個人主線，也沒有增加已驗證學習證據或真實進展。個人內容與識別碼只保留於私人資料庫，不收錄於此公開報告。

第一次保存遇到 PL/pgSQL 區域變數與欄位同名造成歧義，該交易回滾；改用明確的 v_ 變數命名後重跑成功，並重新查核重複數量與原始來源。沒有把失敗交易算成成果。

## 尚不能宣稱

這不是独立多代理的效果比較，不證明所有任務都能完成，不會取消平台額度、授權或時間限制。未對新版學習前端做登入後瀏覽器驗收，也未建立網站自動呼叫 ChatGPT 的後端。卡片保存成功不代表使用者已理解，驗證題仍需本人回答。
