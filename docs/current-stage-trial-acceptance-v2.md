# Current-stage trial acceptance v2

Scope: development validation only. Real-world acceptance remains separate.

## Trial contract
- Entry A: content or topic.
- Entry B: existing goal.
- Render one current stage only.
- The current stage contains one stage goal, one deliverable artifact, and one rule for deciding continue, pivot, or stop after the result.
- Do not render future stages before an artifact result or genuine user feedback exists.
- Trial output stays in browser memory or validation scope and never becomes Personal Home progress, Learning evidence, a personal route, or a personal knowledge link.
- Before an AI provider is connected, label the output as a generic skeleton.

## UI terms
- blocked_external: 外部能力受阻
- Synapse: 知識連結
- Learning Unit: 學習單元
- Live: 已連線
- data_scope=real: 正式個人資料 in user-facing text

## Knowledge-link states
The surface must distinguish loading, empty, error, and ready. Cached or demo content must be explicitly labeled and must not look like current personal data.

## Development acceptance
A frontend implementation is complete only after canonical source readback, JavaScript/static checks, deployment, and rendered behavior verification. Deployment success alone is not acceptance.
