# ADR-0005：全站採用 W1b 定案稿，分三批上線

- 狀態：proposed
- 日期：2026-10-11

## 背景
設計稿 25 頁已定案，含 11 項產品決定；其中一部分需要後端或政策變更。

## 決定
1. 視覺與共用殼先上（純前端）；需要 LLM、公開分享、方案／試用或開放註冊的決定，各自等使用者核准後再做。
2. 系統數字只算「失敗待重試」。
3. 主導覽暫時維持「研究室」（navigation-5-pages 已接受），稿中的「回顧」主導覽等使用者確認。
4. 「第一次登入自動建帳」與個人私人模式衝突，暫不改 `create_user:false`。

## 後果
上線後畫面和稿一致的部分先完成；第 3 批頁面在核准前顯示目前的既有功能。
